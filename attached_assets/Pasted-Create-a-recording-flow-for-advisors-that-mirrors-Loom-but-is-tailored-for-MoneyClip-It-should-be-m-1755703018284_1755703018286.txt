Create a recording flow for advisors that mirrors Loom but is tailored for MoneyClip. It should be minimalist, professional, and designed for financial advisors. The flow covers capture setup, recording with overlay controls, captions, preview with editable fields, optional password, and instant sharing.

Flow & Behavior

1) Capture chooser (modal)

Options: Screen, Window, or Browser Tab.

Highlight border shows which target will be recorded.

Advisor chooses microphone input and whether to include Webcam (PiP bubble) or Profile Photo badge.

Toggles: Show cursor highlights, Countdown before start (default 3 seconds).

Show mic level meter.

Advisor can pre-select Captions On/Off before recording (default = On).

2) Recording

Begin after countdown.

Clear highlight border around capture target.

Always-visible overlay dock (draggable, floating on top):

Pause/Resume

Stop

Mute/Unmute

Camera On/Off or Profile Photo toggle

Captions toggle (On/Off during recording)

Timer + duration indicator

If captions are enabled, live audio transcription runs in the background.

Recorded video stores caption data as a transcript track.

3) Stop → Preview Page
When recording stops, show a Preview page with:

Client Name field (manual entry, above title).

Title & Description auto-generated by AI transcription of audio (editable).

Playback preview of the video with captions (advisor can toggle captions on/off in preview).

Optional trim controls (simple start/end handles).

Optional password field: advisor can set a password viewers must enter to watch.

Webcam/photo toggle: confirm whether it will display on the final viewer page.

Actions: Save or Discard.

When Save is clicked:

Save video, client name, title, description, captions, and password settings.

Generate a unique shareable link.

Show share options: Copy link, Send by Email, Send by Text.

4) Save & Share

Saving shows progress feedback.

After success, a shareable link appears immediately with share options.

Saved video also appears in the Recent Videos section on the Dashboard.

Captions Behavior

Captions are generated automatically by transcribing the advisor’s audio.

Captions appear at the bottom of the video in a clear, minimalist style.

Advisor can toggle captions on/off in Preview before saving.

Viewers can toggle captions on/off while watching.

Transcript file is saved alongside the video for compliance and accessibility.

Compliance & Privacy

Pre-start reminder: “Do not include confidential client info unless you have consent.”

Audit log records: RECORDING_STARTED, CAPTIONS_ENABLED/DISABLED, PAUSED, RESUMED, STOPPED, PREVIEWED, CLIENT_NAME_ADDED, PASSWORD_SET, SAVED, SHARE_LINK_CREATED.

Viewer IPs de-identified if logged.

Error & Recovery

Permission denied → clear instructions + retry.

Unexpected interruption (tab closed, crash) → draft recovery on next load.

Upload failure → retry without losing draft.

Navigating away from Preview without saving → unsaved changes warning.

Acceptance Criteria

Advisor can select capture target, mic, and webcam/photo, start recording with highlight border and overlay dock.

Advisor can toggle captions during recording from the overlay.

Stopping recording → Preview shows: Client Name field, AI-generated title & description, playback preview with captions toggle, optional trim, optional password field.

Saving stores client name, title/description, captions, and password settings.

Shareable link is generated instantly with Copy/Email/Text options.

Captions appear correctly in playback and can be toggled off by advisor or viewer.

Video shows in Recent Videos after saving.

Errors (denied permissions, interruptions, upload failure) are recoverable.

Minimalist, fintech-style UI.

Manual Test Steps

Start a Screen capture with mic + webcam, captions enabled. Confirm countdown, border, overlay dock.

Speak while recording → confirm captions appear in preview and can be toggled off.

Pause/Resume, Stop, then Preview. Confirm Client Name field is present above Title.

Confirm Title/Description are auto-generated and editable.

Enter password, Save → share link is generated with Copy/Email/Text.

Open share link in a new session → password prompt appears, captions toggle works.

Save without password → share link works directly.

Toggle captions off in Preview → video saves without displaying them by default.

Recover from crash mid-recording → confirm draft recovery.

Exit Preview without saving → confirm warning.
